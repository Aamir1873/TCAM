# TCAM

TCAM is a cinematic iPhone camera app with live Technicolor-inspired film processes, lens controls, exposure presets, flash, location-aware watermarks, and captured-photo preview.

## Features

- Cinematic, three-strip, two-strip, and monopack looks
- 0.5×, 1×/2×, and 5×/10× lens controls
- Exposure presets from −1 EV to +1 EV
- 4:3 and 3:4 capture formats
- Full-screen preview after capture
- Optional flash and location-aware photo watermarking

## Requirements

- Xcode 26.6 or newer
- Swift 6 language mode
- iOS 26.4 or newer
- A physical iPhone is recommended for camera testing

## Build

Open `TCAM.xcodeproj` in Xcode, select an iPhone destination, grant camera/photo/location permissions, and run the `TCAM` scheme.
